### Report pipeline (do not break)

```
Field notes
  → POST /api/reports/classify   (7 BMU categories + per-inmate charges)
  → POST /api/reports/extract    (temp=0 schema slots + find_gaps)
  → officer fills Missing Information panel
  → POST /api/reports/generate   (4 reports from structured facts only)
  → POST /api/reports/download   (005/409 DOCX from metadata — no 2nd LLM pass)
```

Guardrails stay mandatory: nullable slots, `invented_facts()`, UNKNOWN markers, charge catalog validation, structured-facts-only generator.
