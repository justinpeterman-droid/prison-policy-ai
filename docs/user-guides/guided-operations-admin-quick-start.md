# Guided Operations Administrator Quick Start

Use individual administrator sign-in and elevation only when the task requires
it. Do not share elevated sessions or record one-time PIN values in tickets,
chat, or Git.

- Use **Overview** and **All Incidents** to find work while preserving the
  recorded attribution for the originating officer and administrator actions.
- Use the **Paperwork Center Daily/Weekly/Monthly** areas for their approved
  purpose. Review revision status before print or restore actions.
- Manage **Accounts & Staff** through approved identity procedures and use
  one-time PIN handling only through the protected delivery path.
- Use **Audit**, **Health**, and **Review Lab** for their authorized support and
  review roles. Do not export sensitive content merely to troubleshoot.
- Respond to sensitive step-up prompts only when you have verified the request
  and are authorized to perform the action.

If a workflow fails, preserve the displayed request ID and use the support and
rollback runbooks. Store completed records in the agency-approved system of
record.
